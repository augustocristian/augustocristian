## Introduction

Git is the de facto standard version control system.
In this lab you will learn the core workflow used in professional teams:

- **Commit** — snapshot of your changes
- **Branch** — isolated line of development
- **Merge / Rebase** — integrate changes
- **Pull Request** — propose and review changes

**Core Git workflow**

```bash
# Initialise and make first commit
git init my-project
cd my-project
echo "# My Project" > README.md
git add README.md
git commit -m "Initial commit"

# Create and switch to a feature branch
git checkout -b feature/login-page

# After making changes...
git add .
git commit -m "Add login page HTML"

# Push branch and open a Pull Request
git push -u origin feature/login-page
```

<Exercise title="Exercise 1.1 — Collaborative Workflow">

Working in pairs:

1. Fork the provided repository on GitHub
2. Each person creates a different feature branch
3. Make a small change on your branch and push it
4. Open a Pull Request targeting `main`
5. Review and approve your partner's PR, then merge it
6. Pull `main` and verify both changes are present
