## What is the World Wide Web?

- Invented by Tim Berners-Lee at CERN (1989)
- A system of interlinked hypertext documents accessed via the Internet
- Key enabling technologies: HTTP, HTML, CSS, JavaScript

## The HTTP Protocol

HTTP follows a **request-response** model between client and server.
Every interaction begins with a client request and ends with a server response.

```http
GET /index.html HTTP/1.1
Host: www.example.com
Accept: text/html

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1234
```

## URLs & Resources

A URL (Uniform Resource Locator) identifies a resource on the Web.

- **Scheme**: `https://`
- **Host**: `www.example.com`
- **Path**: `/products/item`
- **Query**: `?id=42`
