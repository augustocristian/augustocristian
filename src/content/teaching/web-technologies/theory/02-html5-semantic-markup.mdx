## HTML Document Structure

Every HTML document follows a defined structure with a `DOCTYPE`,
a `<head>` (metadata) and a `<body>` (visible content).

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>
```

## Semantic Elements

Semantic HTML conveys meaning about the content:

- `<header>` — introductory content or navigation
- `<nav>` — navigation links
- `<main>` — dominant content of the page
- `<article>` — self-contained composition
- `<section>` — thematic grouping
- `<footer>` — footer for its nearest ancestor
